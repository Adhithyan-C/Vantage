# Vantage
Vantage is a go-to-market intelligence dashboard for B2B SaaS sellers.

## Prerequisites
- Node 20+

## Setup
1. Run `npm install`
2. Copy `.env.example` to `.env` and fill it in
3. Run the SQL files in `supabase/migrations` then `supabase/seed.sql` in the Supabase SQL editor.

## Commands
- `npm run dev:api`
- `npm run dev:web`
- `npm run typecheck`
- `npm test`
